pytorch-multi-node-job -n <your-namespace> --type=merge -p {\"spec\":{\"suspend\":true}}\n6.2.4. Resuming a training job\n\nPrerequisites\n\nYou have a TrainJob that is currently in a suspended state (spec.suspend: true).\nYou have a Persistent Volume Claim (PVC) or S3-compatible storage containing the latest saved checkpoint files from the previous session.\nYour training script is configured to automatically detect and load the most recent checkpoint from the designated storage path upon startup.\nThe cluster has sufficient available resources to fulfill the original resource requests of the job.\n\nProcedure\n\nRun the following command:\n\noc patch trainjob pytorch-multi-node-job -n <your-namespace> --type=merge -p {\"spec\":{\"suspend\":false}}\n\nWhen resumed, the job automatically loads the latest checkpoint and continues training from where it stopped.\n\nFor more information about JIT checkpointing and suspend/resume, see Using RHAI trainers for progress tracking and
